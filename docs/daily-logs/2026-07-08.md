# 2026-07-08 — Lead Flow Alignment

## Built

- Corrected the production lead data class for the initial 50 imported records:
  - `OPEN / AVAILABLE` → `COLD / AVAILABLE`
  - ownership and claim timer fields remain null
  - 1 batch-level audit record and 50 lead-level audit records were written
- Added Cold Lead workspace behavior on `/portal/leads`:
  - Cold Lead list
  - unowned lead detail panel
  - click-to-call logging that records activity before opening the device dialer
  - Cold Lead disposition form
  - claim button only after verified two-way contact
- Added strict click-to-call protection:
  - `/api/portal/leads/call-start` logs `CALL_INITIATED`
  - the client opens `tel:` only after the log succeeds
  - if logging fails, the dialer does not open
  - no owner, claim, soft lock, or timer is created by call start
- Updated claim guard logic:
  - no claim before two-way contact
  - claim requires `twoWayContactAt`
  - 45-day `openPoolReleaseAt` starts when the claim succeeds
- Added DNC support for unowned Cold Lead records.
- Added daily secured lead-aging sweep:
  - returns expired claimed leads to Open Pool after the 45-day claim timer
  - promotes 21-day stale unclaimed Open Pool leads to Shark Tank
  - writes audit and activity evidence for both paths
- Updated `/portal/workspace` into a real My Workspace dashboard:
  - assigned records
  - callbacks
  - claim access
  - recent activity
  - claim-timer responsibility
- Updated `/admin/leads/testing` into a PR #34 Lead Flow Alignment acceptance board.
- Tightened Warm Reply Triage:
  - unowned inbound replies require recorded two-way contact before assignment
  - assignment creates owner follow-up
  - assignment starts the same 45-day timer as normal claim
  - suppressed/DNC/closed/already-owned/no-contact Leads are excluded
- Hardened GHL appointment relay:
  - suppressed/DNC Leads are ignored and audited
  - booked/confirmed/rescheduled events record two-way contact when missing
  - cancelled/no-show events create one owner callback or expedite an existing callback
  - Closed Won Leads are not rolled back by later recovery events
  - webhook response/audit metadata reports ignored/callback/preserved outcomes
- Hardened GHL opportunity relay:
  - suppressed/DNC Leads are ignored and audited
  - Won/Lost terminal outcomes cancel scheduled callbacks
  - late Lost cannot roll back Closed Won
  - webhook response/audit metadata reports ignored/preserved/callback-cancel outcomes
- Added `scripts/check-lead-flow-alignment.ts` and wired it into the build guard sequence.
- Added `docs/LEAD_FLOW_ALIGNMENT_20260708.md` for scope, rule mapping, aging sweep, GHL relay hardening, click-to-call, and acceptance checks.
